# CRICMOTION AI - API Design Documentation
**Version:** 1.0 (Final Foundation)

## 1. Overview and Standards
* **Base URL:** `https://api.cricmotion.ai/v1`
* **Content-Type:** `application/json`
* **Authentication:** All protected routes require a JWT token passed in the header: `Authorization: Bearer <token>`
* **Multi-Tenancy:** The `ownerId` is implicitly extracted from the JWT token on the backend to filter all database queries. Clients never send `userId` or `ownerId` in the request body to prevent privilege escalation.

## 2. Authentication Endpoints

### 2.1 Register / Login (Frictionless Auth)
* **Endpoint:** `/auth/login`
* **Method:** `POST`
* **Description:** Creates a new tenant account or logs in an existing user.
**Request Payload:**
```json
{
  "email": "creator@example.com",
  "password": "SecurePassword123!"
}
```
**Response (200 OK):**
```json
{
  "success": true,
  "token": "eyJhbGciOiJIUzI1NiIsInR5c...",
  "user": {
    "id": "65ab1c2d3e4f5g6h7i8j9k01",
    "email": "creator@example.com",
    "wallet": { "generationCredits": 10 }
  }
}
```

## 3. Project & Workspace Endpoints

### 3.1 Get All Projects (Grid View)
* **Endpoint:** `/projects`
* **Method:** `GET`
* **Description:** Retrieves all projects belonging to the authenticated user for the Dashboard Grid.
**Response (200 OK):**
```json
{
  "success": true,
  "count": 1,
  "data": [
    {
      "id": "65ab1c2d3e4f5g6h7i8j9k02",
      "title": "Pant's Record Breaking Auction",
      "status": "READY",
      "createdAt": "2026-11-17T00:45:00.000Z",
      "artifacts": { "thumbnailUrl": "https://cdn.cricmotion.ai/assets/thumb_65ab1c.jpg" }
    }
  ]
}
```

### 3.2 Initialize New Pipeline Project
* **Endpoint:** `/projects`
* **Method:** `POST`
* **Description:** Initializes a new video project in the `PLANNING_SCRIPT` state from the initial Omnibar prompt. Deducts 1 credit and queues the worker.
**Request Payload:**
```json
{
  "sourcePrompt": "Rishabh Pant sold to LSG for 27 Crores in IPL 2026 auction.",
  "config": {
    "targetDurationSeconds": 60,
    "vibe": "News",
    "avatarModelId": "old_british_reporter_01",
    "voiceModelId": "eleven_multilingual_v2_british"
  }
}
```
**Response (201 Created):**
```json
{
  "success": true,
  "message": "Project initialized and queued.",
  "projectId": "65ab1c2d3e4f5g6h7i8j9k02",
  "status": "PLANNING_SCRIPT"
}
```

## 4. Script & Conversational Revision Endpoints

### 4.1 Get Latest Script (Filmstrip Hydration)
* **Endpoint:** `/projects/:projectId/scripts/latest`
* **Method:** `GET`
* **Description:** Retrieves the active storyboard script generated by Gemini to hydrate the frontend Filmstrip UI.
**Response (200 OK):**
```json
{
  "success": true,
  "data": {
    "versionNumber": 1,
    "contextCategory": "auction-financial",
    "estimatedDurationMs": 45000,
    "scenes": [
      {
        "sceneId": "scene_01",
        "narrationText": "History has been made in the IPL auction!",
        "headlineTickerText": "BREAKING: PANT SOLD TO LSG",
        "overheadAnimations": {
          "primaryAsset": "jersey",
          "primaryAssetData": "17",
          "actionAsset": "money-rain",
          "punchyText": "₹27 CRORE!"
        }
      }
    ]
  }
}
```

### 4.2 Submit Omnibar Revision Chat
* **Endpoint:** `/projects/:projectId/chat`
* **Method:** `POST`
* **Description:** Sends a user's natural language request to Gemini to mutate the script. If the AI determines a script change is needed, it creates `versionNumber + 1` and triggers a partial re-render.
**Request Payload:**
```json
{
  "message": "Make the headline text in scene 1 more aggressive."
}
```
**Response (200 OK):**
```json
{
  "success": true,
  "data": {
    "reply": "I've updated the headline ticker to sound more aggressive for you!",
    "newScriptVersion": 2,
    "pipelineStatus": "RENDERING_VIDEO"
  }
}
```
